## Context

In Symfony applications using standard PSR-4 service discovery (`App\: resource: '../src/'`), Symfony registers private service definitions for all discovered classes found in the directory.

Previously, `IgorDiscoveryPass` was registered without an explicit compiler pass type, defaulting to `PassConfig::TYPE_BEFORE_OPTIMIZATION`. As reported in #87, this executed before Symfony's built-in `RemoveUnusedDefinitionsPass`. Consequently, all unreferenced, private, or dead classes (such as unused utility classes, misplaced DTOs, or unreferenced services) were dumped into `igor_service_map.json`. In large codebases, this significantly inflated the service map (e.g. from 1,574 to 3,880 definitions) and caused Igor to audit classes that never exist at runtime.

Simply moving the compiler pass to `PassConfig::TYPE_AFTER_REMOVING` would introduce an architectural blind spot: `InlineServiceDefinitionsPass` removes single-use private services from `$container->getDefinitions()` and inlines them directly into parent definitions, which would cause Igor to miss stateful inlined services that live permanently in memory within parent singletons.

Closes #87

## Implementation

This PR implements a comprehensive solution that discards unused definitions while ensuring that all inlined services are preserved:

1. **Register `IgorDiscoveryPass` in `PassConfig::TYPE_AFTER_REMOVING`**:
   - `IgorPhpBundle::build()` now registers `IgorDiscoveryPass` with `PassConfig::TYPE_AFTER_REMOVING`.
   - This ensures Symfony's `RemoveUnusedDefinitionsPass` has already executed, filtering out dead and unreferenced service definitions.

2. **Recursively Collect Inlined `Definition` Objects**:
   - In `IgorDiscoveryPass.php`, remaining service definitions are traversed recursively across:
     - Constructor arguments (`$definition->getArguments()`)
     - Method calls (`$definition->getMethodCalls()`)
     - Configurator (`$definition->getConfigurator()`)
     - Factory (`$definition->getFactory()`)
     - Injected properties (`$definition->getProperties()`)
   - Any embedded `Definition` object is extracted, assigned a deterministic identifier (`inlined.<FQCN>.<objectId>`), and registered in `serviceMap['definitions']`.
   - Inlined definitions inherit their parent's shared lifecycle (`$isShared = $parentShared`), ensuring that any stateful helper living in a shared singleton service continues to be audited.
   - Built-in scalar pseudo-types (`int`, `string`, `bool`, etc.) occasionally generated by Symfony factories or closures are safely ignored.
   - Argument wrapper objects implementing `ArgumentInterface` (such as `ServiceClosureArgument`, `IteratorArgument`, and `ServiceLocatorArgument`) are automatically unwrapped via their `getValues()` / `getValue()` methods.
   - For `ServiceClosureArgument`, because closures create fresh instances on demand and are not retained by the parent, wrapped non-shared definitions preserve `shared: false` to avoid false-positive state-leak reports.
   - Each definition in `serviceMap['definitions']` preserves its own individual lifecycle (`shared: false` for standalone prototypes, `shared: true` for inlined singletons), enabling `collectSymfonyServices` to correctly skip prototypes. In the Go auditor, `IsSharedService` and `IsExplicitlyNonShared` examine all definitions of a class to deterministically decide if a class has any shared instance.

3. **Traverse Nested Arguments in Dependency Extraction**:
   - `extractDependencies` now supports nested arrays and traversable structures as well as wrapped arguments (`ServiceClosureArgument`), tracking both `Reference` and inlined `Definition` objects within argument lists.

4. **Automated, Mock & Real Symfony Container Compilation Testing**:
   - Added `TestIgorDiscoveryPass_AfterRemovingAndInlinedDefinitions` and `TestIgorDiscoveryPass_RealSymfonyCompilation` in `cmd/igor/php_wrapper_test.go`:
     - Asserts the pass type is strictly `PassConfig::TYPE_AFTER_REMOVING`.
     - Validates end-to-end execution with real Symfony compiler passes (`InlineServiceDefinitionsPass`, `RemoveUnusedDefinitionsPass`), verifying that dead services are removed, directly inlined services inherit `shared: true`, and closure-wrapped services retain `shared: false`.
